# NovaStore

A complete e-commerce platform built with React, Node.js, Express, MongoDB, and Stripe.

## Overview

- Full-stack storefront and admin experience
- Secure authentication and role-based access
- Product catalog, cart, checkout, and order flow
- Stripe-powered payment intent flow
- MongoDB-backed data layer

## Local Development

See the repository README for the full setup instructions.

```bash
git clone https://github.com/ekhandesameer336-stack/novastore.git
cd novastore
```

## Project Structure

- `backend/` — Express API and business logic
- `frontend/` — React + Vite storefront
- `docs/` — GitHub Pages source
